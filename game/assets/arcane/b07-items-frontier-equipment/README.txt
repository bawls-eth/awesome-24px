ARCANE RPG — Frontier equipment and potions

Sixteen original inventory icons cover the existing Arcane Frontier equipment and potion catalog. All IDs match that catalog. The manifest uses an item category and includes tier and tags for each icon. Tier values are proposed art metadata for review and do not define game balance.

Each single-frame 32 × 32 PNG has binary transparency, at least three pixels of padding and a 24–26 px longest silhouette dimension. Colors use the shared B04 palette. See preview.png and validation-report.json.
