# B06e Frontier Misc Enemies

60 original animation strips and 300 frames for five existing Arcane Frontier enemy IDs: bandit, mimic_chest, undead_soldier, spectral_eye and mushroom_monster.

Each down, up and right view has four idle, six move, five attack and five death frames. Left mirrors right. Cells are 256 × 256 with binary transparency, a clean 4 × 4 pixel grid and anchor (128, 231).

Mimic Chest is closed during idle, hops during movement, reveals teeth during attacks and collapses on death. Spectral Eye uses a consistent hover offset with its body bottom at y=215. Mushroom Monster is a tall fungal brute distinct from Puffcap. Attack attachment points are provisional and should be checked in game.
