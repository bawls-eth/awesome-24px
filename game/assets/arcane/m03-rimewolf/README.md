# M03 Rimewolf

Original heavy tundra wolf with a bright frost ruff. Fourteen hostile strips preserve the B40c IDs, 192×192 S48 cells, timing and anchor. Six independent rideable body strips and six saddle overlays use L96 native animation and 384×384 PNG cells. Rideable body and saddle share their anchor and per-frame seat points. Claude will need to bind the new mount IDs during integration.
