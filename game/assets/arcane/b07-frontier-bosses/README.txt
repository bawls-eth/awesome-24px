ARCANE RPG — B07 Frontier bosses

This is the boss portion of B07. It contains 48 down-facing strips across the eight existing Arcane Frontier boss IDs. Each boss has four idle, six move, six attack A, six attack B, two hit and eight death frames.

Each transparent PNG uses 384 × 384 cells, a 4 × 4 pixel grid and a 12 px minimum margin. The manifest anchor is (192,350). The occupied silhouette ends on row 351 to align with the four-pixel grid. Each attack frame includes an estimated effect origin. The game supplies effects separately.

The 16 original source atlases were illustrated with the built-in image generator. Each pair of atlases was scaled to match standing size. A sheet-wide mirror aligned the Void Oracle staff grip. Two Dread Knight wind-up frames use alternate poses from its original atlases to avoid visibly clipped blades.
