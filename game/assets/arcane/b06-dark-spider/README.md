# B06 Dark Spider

12 original animation strips for the existing Arcane Frontier enemy ID `dark_spider`. Each view has four idle, six scuttle, five attack and five death frames. The art uses the shared enemy palette, 256 × 256 cells and the (128, 231) ground anchor. Left mirrors right.

Idle movement is subtle. The side-view pounce reads mainly through leg lift. Attack muzzle points are provisional attachment locations. See the contact sheet for all poses.
