ARCANE RPG B02 v2 — Rogue, Warlock and Paladin

This redraw replaces all 63 strips using the same asset IDs and relative paths. It includes idle, walk, attack, cast, roll, hit and death in down, up and right views for each class.

Nine original source sheets were generated with the built-in image generator using the v1 class triptychs as visual references. The source sheets cover movement, combat and reactions for each class. Source idle poses measure 153–182 pixels tall. Each exported direction starts at 148 pixels tall, with a 231-pixel baseline in all 306 frames. Each walk uses six individually illustrated poses. Exports use the shared B01/B02 palette.

The Rogue carries silver daggers and a crimson scarf. The Warlock carries a violet orb and wears a horned helm. The Paladin carries a gold and blue shield and a square warhammer. See known_issues.json for transitions and muzzle calibration to review in Pixeltown.
