# B06d Frontier Slimes, Swamp and Desert

72 original animation strips and 360 frames for six existing Arcane Frontier enemy IDs: slime_green, slime_red, slime_blue, swamp_leech, toxic_serpent and sand_scorpion.

Each down, up and right view has four idle, six move, five attack and five death frames. Left mirrors right. Cells are 256 × 256 with binary transparency, a clean 4 × 4 pixel grid and anchor (128, 231).

The three slimes share a family silhouette while keeping distinct green, ember-red and frost-blue identities. Attack attachment points are provisional and should be checked in game.
