# B25 Dungeon tilesets

57 original 32 × 32 assets. Each biome provides opaque floor and wall variants plus transparent overlays for doors, torches, pillars and rubble. Torch frames run left to right at 8 fps. Preview shows 3 × 3 mixed-variant tiling and objects composited over floors. Boss floors, the key door and the two chest states use the boss palette.
