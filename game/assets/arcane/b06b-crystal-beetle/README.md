# B06b Crystal Beetle

12 original animation strips for the existing Arcane Frontier enemy ID `crystal_beetle`. Each of the down, up and right views has four idle, six move, five attack and five death frames. The 256 × 256 cells use the shared enemy palette and a (128, 231) ground anchor. Left mirrors right.

Attack muzzle points are provisional. The contact sheet shows all 60 frames.
