# Arcane Frontier — original action RPG asset pack

This is a NEW game world. Do not merge with the earlier flora/fauna assets.

**Contents:** 100 original 32x32 transparent PNG sprites (terrain tiles are opaque), `manifest.json`, raw 10x10 atlas, labeled preview catalog, and `GAME_BUILD_PROMPT.md`.

**Integration:** paste `GAME_BUILD_PROMPT.md` into your game-building AI alongside this zip. Preserve the `assets/<category>/<id>.png` paths. Render nearest-neighbor at integral scale.

**Important:** These are static prototype sprites, not finished production art. They do not contain frame-based animations, audio, GLB models, collision maps, gameplay code or networking. Your AI builder must implement those systems.
