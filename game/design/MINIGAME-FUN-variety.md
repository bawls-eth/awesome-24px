# Mini game fun notes: seeded run variety

1. A run modifier is a "one more try" reason only if the player can read it in one line before they start (name + effect on the card).
2. Show it where the eyes already are during play (HUD tag) and again on the result, so the score makes sense in context.
3. Honest odds: list every modifier and its chance (equal odds, 1 in N); no hidden weighting, no paid rerolls, nothing to buy.
4. Effects must be numbers the player can check (x0.8 points, 70% speed, 4 tiles instead of 3), never vague "luckier" wording.
5. Seeded, not random-at-the-wire: the same seed gives the same layout and modifier, so "Replay seed" is a fair retry of one run.
6. Keep modifier bests apart from plain bests; a lucky modifier must never overwrite a hard-won plain record.
7. Long-term rules (stars, medals, unlocks) stay exactly as they were; variety lives inside the run only.
8. No streaks, timers or "today only" framing: the next run's modifier is just shown on the card, ready when the player is.
9. An off switch (?mods=0) for players who want the plain game, and visual extras (glow, wind) stay still with reduced motion / low gfx.
10. Practice-only variety (Stalk Market moods) must never touch the real save; say so on screen.
