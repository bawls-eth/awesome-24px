# Beta b15: edge cases, accessibility, input devices, hostile use

Time spent: about 30 minutes wall-clock (machine heavily shared, several runs timed out and were rerun in the background).

## Covered
- All 14 pages loaded at 320x568 (touch) with hostile query strings (XSS in seed/from/mut, `../../../etc`, `island=-1e999`, `floor=NaN`, 20-digit `deep`, NUL + 3000-char `party`): no XSS, no pageerror, no horizontal scroll (except arcane-frontier). Town with `?test=1&seed=<b>` and a 5000-char param: fine.
- Hostile saves: `pixeltown-save-v1` / `pixeltown-access-v1` with XSS names, 1e308, NaN, Infinity, `__proto__`, plus every other pixeltown/mm key set to an XSS string: hub, town, realm, isles, angler, dash, deepdelve, echo, jam, pop all rendered, no injection (results for stack, stalk, fest and the clock-jump run did not finish before I wrote this).
- Town name input caps at 16 chars; a `<img onerror>` name is rendered as plain text above the avatar (escaped).
- localStorage throwing on every page (see b15-01, b15-02).
- Keyboard: 40 Tab presses on 11 pages (order, focus ring, hidden focus), Esc opens the Realm menu with focus on Resume.
- Emulated Xbox gamepad (navigator.getGamepads): Realm stick moves, Start (button 9) opens the backpack panel (needs >1 frame hold in software rendering, fine).
- Touch: 3-finger CDP multi-touch, drag off-screen (-50, 2000), long press in Town: no error, scene alive.
- Resize mid-play in Realm 1280x720 -> 320x568 -> 568x320 -> 2560x1440 -> 1280x720: canvas always matches, no scroll. Town rotate portrait/landscape OK.
- hudScale 1.5 + reduce-motion at 390x844 (Realm shows first-run hero picker, no overlap; hub/isles/angler fine) and 200% zoom emulation (195 css px).
- Offline mid-play in Town (Menu still opens, scene active). Hidden/visible tab and back/forward in Realm: stays alive, no error.
- 2560x1440 loaded (screenshots only skimmed).

## Not reached
Date-override clock jumps (script written, result not read), same page open in two tabs, high contrast visual check, Deepdelve/Isles actual play with pad, Lantern Camp, Bug Safari (festival path in my list 404'd: the page is `bugs`, not `festival`, my mistake), low-graphics pref, reduced-motion visual diff, real screen-reader pass, CDP offline reload per page (no service worker so every reload is the browser error page).
