# Cycle 0, Lead Developer: whole-codebase review

Branch `cyc0-lead` (cut from `r4-integ2` f44bf65). Scope: `game/*.js`, `game/shared/*`, `game/hub/*`, `game/games/*` (about 59,000 lines; `net.js` and
`firebase-config.js` read only). Method: grep sweeps (clock use, storage, JSON.parse, timers, listeners, innerHTML), a scripted scan for storage
access outside `try`, eslint with bug-class rules only (dupe keys, unused locals, self-compare, loop conditions), a reference scan of every shipped
file, and a read of the hot paths (Town `update`, Realm `_loop` / `_update` / `_syncHud`, Isles `frame`, Underground loop).

Overall: storage and JSON handling are in good shape (every `JSON.parse` of stored data and every storage read sits in a `try`; the few bare
`setItem` calls have a guarded caller). No page-level timer or listener leak was found in production paths. The real defects were clock logic and
one hot path.

## Checked and found clean (no action)
- `JSON.parse` of stored data: all in `try` (mm-gift, mm-access, realm, main, deepdelve, lantern, mad-maze, backup). Storage reads: all guarded;
  bare `setItem` in dash / echo / pop / stack `writeSave` and main.js `commitRestore` have a guarded caller.
- Timers: every `setInterval` is page-life or cleared (`_ugExitHintInterval`, tutorial poll, world-team). Underground `stop()` removes its
  listeners and disposes textures, materials, geometries and the renderer. Realm `destroy()` removes everything except L-11.
- `innerHTML` in main.js: only static strings, escaped rows (`escapeHtml`) and the changelog renderer.
- eslint `no-self-compare` (16) are NaN checks; `no-unmodified-loop-condition` (7) are loops whose callee changes the state. No real hits.
- Date helpers: mm-daily (UTC key, strict `cleanDate`), mm-stalk-market (local date + local slot, one clock), angler (local date + local hour),
  isles (one `clock.now()`), lantern (UTC, future dates refused).
