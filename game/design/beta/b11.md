# b11 beta report: Stalk Market, Deepdelve, Lantern Camp

Time spent about 35 min wall clock (machine load 12+, browser slots queued for minutes, so coverage is narrower than planned).

## Covered
- Stalk: real market on a fake clock (Sunday buy, Mon-Sat price walk, Sat PM sell, rollover with spoilage, 0-bells rollover tops up to 1,000, backwards clock in the same week), practice week with moods end to end, phone layout, console clean.
- Deepdelve: load on phone and desktop (software GL, about 58-60 fps measured over 3 s, no errors), Craft/Goals/Menu panels, dive summary card, place/mine ore loop via test API, source review of mining, crafting, dive scoring.
- Lantern: fresh first screen, create hero, Rekindle, class unlocks, Start run into the Realm, hostile name text (shown literally, safe).

## Not reached
Stalk neighbours and goals through the UI, medals; Deepdelve wyrm, mobs, other modifiers, pointer lock, touch drag mining, creative world; Lantern stash moves, backup/restore, Fall/retire, abilities sheet. No video clips.

1. P2 Rekindle works on living heroes: free clones; a level-20 hero yields level-10 heroes with no Fall (b11-01).
2. P2 Dive score is farmable: ore blocks are placeable and re-minable; 100 loops gave score 1800 at depth 0 (b11-02).
3. P3 Same-week clock moves reopen Sunday buying and reveal future prices (b11-03).
4. P3 Neighbours are a strictly better deterministic sell price (b11-04).
5. P3 Craft panel titles like 'plank > plank' (b11-07).
6. P3 First practice loss becomes 'Practice best' (b11-05); compass button overlaps practice heading (b11-06).
7. P3 Lantern fresh-start messaging (b11-09); Depth 5 at surface, bland first view (b11-08).

## Felt great
Stalk is clear: one-line entry, honest odds, readable stepped chart, good end-of-week card. Deepdelve ran at full fps even with software GL. Lantern first screen is calm and short.
