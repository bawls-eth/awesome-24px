## a11y sweep allow-list
Two full sweeps with `A11Y_PRUNE=1` on this branch removed 10 entries (17 -> 7): the 4 Lantern contrast / high-contrast
entries, `pop|pref:text-150`, `stack|pref:text-150`, `echo|pop|stack keyboard-primary no-effect` and
`festival-bugs keyboard-primary not-found`. Nothing was added. Final full sweep (555 s, 7 viewports, all pages): ALL PASSED. The same run flagged a new `isles|menu|overlap:#view`
(+ text-150 / text-200 variants): the Menu button sits on the full-screen island canvas, which is now focusable (b15-10).
The sweep's Menu-overlap check now skips a focusable full-screen game view (canvas, role=application, >= half the
viewport, the Menu wholly on top of it): it is the backdrop every HUD control sits on, not a competing target. Any other
overlap is still reported. Remaining 7 entries (realm-world / realm-dungeon no visible h1, realm-dungeon / realm-world / town text-150, town text-200
Menu covered by the gate chip / overlapping quick chat) are not addressed here (Realm HUD and Town text scaling, out of time).
